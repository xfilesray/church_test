教會事奉管理與恩典紀錄系統

為同工與團隊打造的簡報/文件版專案介紹與完整核心代碼彙整

專案簡介與設計初衷

本系統旨在協助教會更有效率地處理「事奉排班」、「場地/房間借用」以及「屬靈恩典紀錄」。

考慮到跨平台部署（如 Streamlit Cloud）時經常遇到的多國語系編碼與中文渲染 Bug，本系統採用嚴格的前後端架構分離原則設計：

前端與核心邏輯 (app.py)

維持純英文變數與結構代碼，確保程式運行極致穩定、零編碼衝突。

語系與模組設定 (constants.py)

將所有繁體中文 UI 標籤、選單選項與 Dataframe 欄位對照表集中管理，方便維護與擴充。

核心功能亮點

三合一多功能紀錄表單

  • 恩典與體會日記：即時數算神的恩典、紀錄團隊服侍的心得與禱告事項。
  • 未來事奉人手排班：涵蓋敬拜隊、主日學、音控/直播、接待等多項崗位。
  • 房間/場地借用：管理大堂、副堂與各小組教室的借用時段與聯絡人。
  • 彈性自訂選項：選擇「其他」時動態展開輸入框，方便填寫特殊事項。

智慧防錯與防衝突機制

  • 同工重複排班預警：自動解析多人名字（相容中英文逗點），重複時即時提醒。
  • 場地撞期警示：同房間、同時間若已有預約，主動阻擋並發出衝突通知。
  • 強制儲存彈性：提供 Force Save 按鈕因應特殊聯合聚會特例。

前後端分離數據整合

  • Supabase (PostgreSQL)：作為雲端資料庫，確保資料安全與跨裝置同步。
  • Pandas 資料整合：前端整合 Pandas 提供快速關鍵字搜尋與美觀表格展示。

整合功能函式庫 (System Core Functions)

以下將所有與資料庫存取、衝突檢測、資料解析及邏輯處理之 Function 完整匯整如下：

database.py & helper_functions.py (組合整合檔)
import re
import pandas as pd
from supabase import create_client, Client

# ==========================================
# 1. 資料庫連線初始化 (Database Initialization)
# ==========================================
def init_supabase_client(url: str, key: str) -> Client:
    """建立並傳回 Supabase Client 實例"""
    return create_client(url, key)

# ==========================================
# 2. 姓名解析與比對函式 (Name Parsing Helpers)
# ==========================================
def parse_personnel_names(raw_text: str) -> list[str]:
    """相容中英文逗點、空格與換行，將輸入之同工名單拆解為乾淨 List"""
    if not raw_text:
        return []
    names = re.split(r'[,，\s\n]+', raw_text.strip())
    return [name for name in names if name]

# ==========================================
# 3. 衝突檢測核心邏輯 (Conflict Detection)
# ==========================================
def check_schedule_conflicts(supabase: Client, target_date: str, time_slot: str, 
                             room_name: str, personnel_list: list[str]) -> dict:
    """
    檢查場地撞期與人員重複排班衝突
    Returns: {'has_room_conflict': bool, 'conflicting_people': list[str]}
    """
    # 抓取該日期與時段的現有資料
    response = supabase.table("church_records")\
        .select("*")\
        .eq("event_date", target_date)\
        .eq("time_slot", time_slot)\
        .execute()
    
    existing_records = response.data
    room_conflict = False
    conflicting_people = []

    for rec in existing_records:
        # 檢測場地衝突
        if room_name and rec.get("room_name") == room_name:
            room_conflict = True
        
        # 檢測人員重覆排班衝突
        existing_names = parse_personnel_names(rec.get("personnel", ""))
        for p in personnel_list:
            if p in existing_names:
                conflicting_people.append(p)

    return {
        "has_room_conflict": room_conflict,
        "conflicting_people": list(set(conflicting_people))
    }

# ==========================================
# 4. 資料庫 CRUD 操作函式 (CRUD Operations)
# ==========================================
def insert_church_record(supabase: Client, data: dict) -> dict:
    """將新筆記錄寫入 Supabase 資料庫"""
    response = supabase.table("church_records").insert(data).execute()
    return response.data

def fetch_all_records(supabase: Client) -> pd.DataFrame:
    """從資料庫讀取所有紀錄並轉為 Pandas DataFrame"""
    response = supabase.table("church_records").select("*").order("created_at", desc=True).execute()
    if response.data:
        return pd.DataFrame(response.data)
    return pd.DataFrame()

def search_records(df: pd.DataFrame, keyword: str) -> pd.DataFrame:
    """進行動態關鍵字搜尋對應項目"""
    if df.empty or not keyword:
        return df
    
    mask = df.apply(lambda row: row.astype(str).str.contains(keyword, case=False).any(), axis=1)
    return df[mask]
